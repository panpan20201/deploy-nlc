# Установка на новый компьютер

Инструкция для чистого компьютера с Windows 10/11. Шаги выполняются по
порядку. Большую часть проверок и установки делает скрипт
`tools/setup.ps1`. Вручную остаются установка внешних программ, подготовка
планшета и заполнение `.env`.

Если вы работаете с Claude Code, откройте папку проекта и попросите:
«установи систему по docs/INSTALL.md». Шаги, помеченные **[вручную]**,
требуют человека: физический доступ к планшету, вход в аккаунты,
подтверждения Windows.

## 1. Программы [вручную]

### 1.1. Python 3.12

1. Скачайте Python 3.12 с https://www.python.org/downloads/.
2. В установщике отметьте **«Add python.exe to PATH»** и оставьте
   включённым «py launcher».
3. Проверка: `py -3.12 --version`.

### 1.2. Node.js и Appium

1. Установите Node.js 24 LTS с https://nodejs.org/.
2. В новом окне командной строки:
   ```bat
   npm install -g appium@3.6.0
   appium driver install uiautomator2@8.4.0
   ```
3. Проверка: `appium --version` и `appium driver list --installed`.

### 1.3. Java

Установите JDK 17 или новее, например Temurin LTS с https://adoptium.net/.
Проверка: `java -version`.

### 1.4. Android SDK

Драйверу uiautomator2 нужен Android SDK с **platform-tools** и
**build-tools** и переменная окружения **`ANDROID_HOME`**. Одних
Platform Tools недостаточно: без build-tools Appium не может подписать и
установить на планшет свой служебный сервер.

Android Studio не нужен. Порядок:

1. Скачайте «Command line tools only» для Windows:
   https://developer.android.com/studio#command-line-tools-only
2. Распакуйте так, чтобы получилось
   `C:\Android\sdk\cmdline-tools\latest\bin\sdkmanager.bat`
   (папку `cmdline-tools` из архива переименуйте в `latest` и положите в
   `C:\Android\sdk\cmdline-tools\`).
3. Установите компоненты:
   ```bat
   C:\Android\sdk\cmdline-tools\latest\bin\sdkmanager.bat --sdk_root=C:\Android\sdk "platform-tools" "build-tools;34.0.0"
   ```
   Лицензии подтвердите вводом `y`.
4. Задайте переменные окружения пользователя (`Win+R` → `sysdm.cpl` →
   «Дополнительно» → «Переменные среды»):
   - `ANDROID_HOME` = `C:\Android\sdk`
   - в `Path` добавьте `C:\Android\sdk\platform-tools`

   или одной командой в PowerShell:
   ```powershell
   [Environment]::SetEnvironmentVariable('ANDROID_HOME', 'C:\Android\sdk', 'User')
   $p = [Environment]::GetEnvironmentVariable('Path', 'User')
   [Environment]::SetEnvironmentVariable('Path', "$p;C:\Android\sdk\platform-tools", 'User')
   ```
5. Откройте **новое** окно командной строки и проверьте: `adb version`.

Переменные окружения подхватываются только новыми окнами. Если Appium
уже был запущен, перезапустите его.

## 2. Планшет

### 2.1. Отладка по USB [вручную]

1. Настройки → Сведения о планшете → Сведения о ПО → 7 раз нажмите
   «Номер сборки».
2. Параметры разработчика → включите «Отладка по USB».
3. Подключите планшет кабелем, на экране подтвердите «Разрешить отладку
   по USB» с галочкой «Всегда разрешать с этого компьютера».
4. Проверка: `adb devices` показывает планшет со статусом `device`.
   Серийный номер из первой колонки впишите в `.env` как `ANDROID_UDID`.

### 2.2. Аккаунты и приложения [вручную]

1. **Язык системы — русский** (Настройки → Общие настройки → Язык).
   Кнопки системных диалогов распознаются по словам на русском,
   английском и корейском, но в эксплуатации проверен русский.
2. **Войдите в Google-аккаунт.** Без него не работает сброс рекламного
   идентификатора, которым снимается дневной лимит HeyDealer.
3. Установите из Google Play **Carmoodo** и **HeyDealer**, откройте каждое
   приложение один раз и пройдите стартовые экраны.
4. В Carmoodo войдите в аккаунт и включите **자동로그인** (автовход). Те же
   логин и пароль впишите в `.env` (`CARMOODO_USERNAME`, `CARMOODO_PASSWORD`).
5. В Google Play отключите **автообновление** Carmoodo и HeyDealer (страница
   приложения → ⋮ → «Автообновление»). Автоматизация привязана к экранам
   приложений; обновление может их изменить, поэтому обновлять лучше
   осознанно и с проверкой.
6. Не ставьте PIN, пароль или графический ключ на экран блокировки: с ними
   автоматика не сможет начать работу, если экран погас. Время до
   отключения экрана — 30 минут (как в эксплуатации).
7. Держите планшет на зарядке.

### 2.3. Рабочие настройки (автоматически)

После установки зависимостей (раздел 3) выполните:

```bat
powershell -ExecutionPolicy Bypass -File tools\setup.ps1 -ConfigureTablet
```

Скрипт через adb:

- отключает анимации (`window_animation_scale`,
  `transition_animation_scale`, `animator_duration_scale` = 0) — так
  экраны появляются сразу и ожидания стабильнее;
- закрепляет портретную ориентацию;
- устанавливает, включает и делает активной клавиатуру ADBKeyBoard —
  без неё не вводится корейский текст;
- запрещает уведомления HeyDealer: всплывающее уведомление может
  перехватить нажатие автоматики.

## 3. Проект

1. Скопируйте папку проекта, например в `C:\Deploy NLC`. Путь без
   кириллицы надёжнее.
2. Запустите установку:
   ```bat
   cd "C:\Deploy NLC"
   powershell -ExecutionPolicy Bypass -File tools\setup.ps1
   ```
   Скрипт проверит программы из раздела 1, создаст `venv`, установит
   зависимости из `requirements-lock.txt` и Chromium для Playwright,
   создаст `.env` из `.env.example`, прогонит тесты и проверит планшет.
   В конце — таблица с результатом каждого шага; строки `FAIL` нужно
   исправить и запустить скрипт снова.

   То же вручную:
   ```bat
   py -3.12 -m venv venv
   venv\Scripts\activate
   pip install -r requirements-lock.txt
   playwright install chromium
   copy .env.example .env
   set PYTHONIOENCODING=utf-8
   python -m unittest discover -s tests -p "test_*.py"
   ```

3. **[вручную]** Заполните `.env`: как минимум `BOT_TOKEN`,
   `ADMIN_CHAT_ID`, `ANDROID_UDID`, учётные данные Carmoodo и PARTSNUMBER,
   по желанию `DEEPL_API_KEY`. Описание каждой строки — в самом файле.

4. Повторите `tools\setup.ps1`. Когда `BOT_TOKEN` задан, скрипт запускает
   стартовые проверки бота (планшет, Appium, приложения, клавиатура,
   эталоны, связь с каталогом) без подключения к Telegram. Для проверки
   Appium его нужно предварительно запустить в отдельном окне (`appium`).

### Перенос с работающего компьютера

Если система переезжает, перенесите вместе с проектом (лично, флешкой):

- `.env` — настройки и пароли;
- `vehicles.db` — база проверенных машин: каждая запись экономит запрос к
  сервисам с дневным лимитом;
- `translation_cache.json` — кеш переводов.

**Одновременно может работать только один экземпляр бота с одним
`BOT_TOKEN`.** Перед запуском на новом компьютере остановите бота на
старом (закройте его окна и уберите ярлык из автозагрузки), иначе два
экземпляра будут перехватывать сообщения друг у друга.

## 4. Первый запуск вручную

1. В первом окне: `appium`. Дождитесь строки
   `Appium REST http interface listener started`.
2. Во втором окне:
   ```bat
   cd "C:\Deploy NLC"
   venv\Scripts\activate
   python bot.py
   ```
   В выводе — список стартовых проверок, все строки с ✅, затем
   `Бот запущен и готов принимать сообщения`.
3. **[вручную]** Отправьте боту ссылку на объявление Encar. В ответе должны
   прийти все разделы: VIN, история ремонта, детали и дата выпуска.
   Первая проверка занимает 1–2 минуты.
4. Команда `/diag` в чате должна показать все проверки с ✅.
5. Остановите оба окна (`Ctrl+C`).

## 5. Постоянная работа

1. Ярлык на `start_all_auto.bat` положите в автозагрузку: `Win+R` →
   `shell:startup` → перетащите туда ярлык (правой кнопкой по файлу →
   «Создать ярлык»). При входе в Windows скрипт дождётся планшета,
   поднимет Appium и запустит бота с автоперезапуском.
2. **Питание:** Параметры → Система → Питание — при работе от сети не
   уходить в сон и не отключать экран надолго; в Центре обновления
   Windows задайте «период активности», чтобы перезагрузки не приходились
   на рабочее время.
3. **После перезагрузки** бот поднимается только после входа пользователя
   в Windows. Для работы без участия человека настройте автовход:
   `Win+R` → `netplwiz` (если флажка «Требовать ввод имени пользователя и
   пароля» нет — в «Параметры → Учётные записи → Варианты входа»
   отключите «Для повышения безопасности разрешить вход Windows Hello…»).
4. Проверка автозапуска: перезагрузите компьютер, войдите в систему и
   через минуту отправьте боту `/status`.
