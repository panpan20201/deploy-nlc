# Deploy NLC — проверка истории автомобилей с Encar

Telegram-бот для проверки подержанных корейских автомобилей. Принимает
ссылку на объявление Encar (поддерживаются также ссылки KB Chachacha) и
отвечает сводным отчётом: VIN, история ремонта, детали комплектации и дата
выпуска.

Данные собираются из нескольких источников:

| Раздел отчёта | Источник | Как получается |
|---|---|---|
| Госномер, комплектация, VIN объявления | Encar / KB Chachacha | HTTP-запросы |
| VIN | приложение Carmoodo | Android-планшет через Appium |
| История ремонта | приложение HeyDealer | Android-планшет через Appium, перевод через DeepL |
| Детали и дата выпуска | каталог PARTSNUMBER | VMware Horizon в браузере (Playwright + OpenCV) |

Подробное устройство — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

---

## Требования

- Windows 10/11 (скрипты запуска — `.bat`; код на Python кроссплатформенный,
  но эксплуатируется на Windows).
- Python 3.12 (проверено на 3.12.10; 3.11 также поддерживается).
- Node.js LTS и Appium 3 с драйвером `uiautomator2`.
- Java JDK 17+ и Android SDK (platform-tools и build-tools), переменная
  `ANDROID_HOME`.
- Физический Android-планшет, подключённый по USB, с установленными
  HeyDealer, Carmoodo и ADBKeyBoard (`ADBKeyboard.apk` в корне проекта).
- Учётные записи: Telegram-бот (@BotFather), Carmoodo, PARTSNUMBER;
  по желанию — ключ DeepL API.

Пошаговая установка на чистый компьютер с эталонными версиями —
[docs/INSTALL.md](docs/INSTALL.md). Для Claude Code в корне лежит
`CLAUDE.md`: достаточно попросить «установи систему по docs/INSTALL.md».

## Установка

Автоматически (проверка программ, venv, зависимости, Chromium, `.env`,
тесты, планшет):

```bat
powershell -ExecutionPolicy Bypass -File tools\setup.ps1
```

Вручную:

```bat
cd "C:\Deploy NLC"
py -3.12 -m venv venv
venv\Scripts\activate
pip install -r requirements-lock.txt
playwright install chromium
```

`requirements-lock.txt` фиксирует точные версии, на которых проект
работает в эксплуатации. `requirements.txt` — список прямых зависимостей с
минимальными версиями; его стоит использовать при осознанном обновлении
библиотек (после обновления прогоните тесты и пересоберите lock-файл
командой `pip freeze > requirements-lock.txt`).

`playwright install chromium` обязателен отдельной командой: `pip` сам
браузер не скачивает.

## Настройки (`.env`)

```bat
copy .env.example .env
```

и заполните значения. Каждая переменная описана в `.env.example`.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | Токен Telegram-бота |
| `ADMIN_CHAT_ID` | рекомендуется | chat_id администратора: оповещения о поломках, копии отчётов |
| `ANDROID_UDID` | рекомендуется | Серийный номер планшета (`adb devices`) |
| `ANDROID_DEVICE_NAME` | нет | Имя устройства, если `ANDROID_UDID` не задан |
| `APPIUM_SERVER_URL` | нет | По умолчанию `http://127.0.0.1:4723` |
| `ANDROID_HOME` | нет | Папка Android SDK, если `adb` не в PATH |
| `CARMOODO_USERNAME`, `CARMOODO_PASSWORD` | рекомендуется | Автоматический повторный вход в Carmoodo |
| `PARTSNUMBER_LOGIN_URL`, `PARTSNUMBER_USERNAME`, `PARTSNUMBER_PASSWORD` | для раздела деталей | Доступ к каталогу PARTSNUMBER |
| `PARTSNUMBER_TEST_VIN`, `PARTSNUMBER_DEBUG` | нет | Ручной запуск и подробный лог PARTSNUMBER |
| `DEEPL_API_KEY` | нет | Перевод незнакомых терминов истории ремонта |
| `REPAIR_HISTORY_TTL_DAYS` | нет | Срок свежести истории ремонта в базе (30) |
| `MAX_ADS_RESETS_PER_DAY`, `MIN_SECONDS_BETWEEN_ADS_RESETS` | нет | Предохранители сброса рекламного ID |
| `HEYDEALER_TREE_PROBE` | нет | Диагностический режим HeyDealer (0) |

При старте бот проверяет настройки и пишет в лог, какая функция не будет
работать без каждой незаполненной строки. Без `BOT_TOKEN` бот не
запускается.

Файл `.env` содержит пароли: не публикуйте его и не пересылайте через
чаты и почту.

## Запуск

**Вся система одним кликом** — `start_all.bat`: дожидается планшета,
поднимает Appium в отдельном окне и запускает бота с автоперезапуском.
Оба окна («Appium Server» и окно бота) должны оставаться открытыми.

**Автозапуск при входе в Windows** — ярлык на `start_all_auto.bat` в папке
автозагрузки (`Win+R` → `shell:startup`). Этот вариант не ждёт нажатия
клавиши.

**Только бот** (Appium уже запущен):

```bat
venv\Scripts\activate
python bot.py
```

`run_bot_forever.bat` запускает `bot.py` в цикле: после падения бот
перезапускается через 10 секунд, каждый перезапуск пишется в
`watchdog.log`.

Готовность подтверждается двумя признаками:

1. В окне бота при старте выводится список проверок — все строки с ✅.
   Под строкой с ❌ написано, что нужно исправить.
2. Команда `/status` в чате отвечает «🟢 Бот работает».

### Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Как пользоваться |
| `/status` | Занятость планшета, расход лимитов, статистика базы |
| `/diag` | Полная проверка оборудования прямо в чат |
| `/resetads` | Ручной сброс рекламного ID (снятие лимита HeyDealer) |

Чтобы перепроверить машину, не глядя в базу, добавьте к ссылке слово
**«обнови»**.

### Служебные утилиты

| Файл | Назначение |
|---|---|
| `tools/setup.ps1` | Установка и проверка окружения (`-CheckOnly`, `-ConfigureTablet`) |
| `calibrate_partsnumber.py` | Калибровка координат интерфейса PARTSNUMBER |
| `cleanup_bad_parts.py` | Поиск и удаление испорченных карточек PARTSNUMBER из базы |
| `backup.py` | Резервная копия `vehicles.db` (вызывается ботом автоматически) |
| `partsnumber_date.py`, `carmoodo_vin.py`, `heydealer_history.py`, `encar_parser.py` | При запуске напрямую — ручная проверка отдельного шага |

## Тесты

Тесты работают на заглушках и сохранённых дампах экранов, без планшета,
Appium и сети:

```bat
venv\Scripts\activate
set PYTHONIOENCODING=utf-8
python -m unittest discover -s tests -p "test_*.py"
```

Дампы экранов, на которых основаны тесты, лежат в `tests/fixtures/`.

Отдельного шага сборки у проекта нет: это Python-приложение, которое
запускается из исходников. Линтер и проверка типов в проекте не настроены.

## Развёртывание

Бот, Appium и планшет работают на одном компьютере; планшет подключён по
USB, поэтому развёртывание локальное. Порядок для нового компьютера —
[docs/INSTALL.md](docs/INSTALL.md). Кратко:

1. Установить Python, Node.js + Appium + `uiautomator2`, JDK, Android SDK.
2. Подготовить планшет: отладка по USB, приложения, ADBKeyBoard.
3. Скопировать проект и запустить `tools\setup.ps1`.
4. Создать `.env`.
5. Проверить ручным запуском, затем добавить `start_all_auto.bat` в автозагрузку.
6. Отключить сон и автоматическую перезагрузку Windows.

Бот стартует при входе пользователя в Windows, а не при включении
компьютера: после перезагрузки нужен вход в систему (или настроенный
автовход).

### Данные

| Файл / папка | Что это | Переносить при переезде |
|---|---|---|
| `vehicles.db` | База проверенных машин (SQLite) | **Да** — главный накопленный актив |
| `backups/` | Автоматические копии базы (14 последних) | По желанию |
| `usage_counters.json` | Дневные счётчики лимитов | Нет |
| `translation_cache.json` | Кеш переводов DeepL | Желательно |
| `logs/` | Журналы работы | Нет |
| `.env` | Настройки и пароли | Да, только лично (флешкой) |

Все эти файлы создаются автоматически и не входят в репозиторий.

## Логи

`logs\nlc.log` — основной журнал: в файл пишется уровень DEBUG, ротация по
5 МБ, хранится 11 файлов. У каждой проверки короткий код вида `a3f19c`; он
стоит в каждой строке лога этой проверки и показывается пользователю в
сообщении об ошибке:

```
2026-08-21 14:11:40 INFO [16f58c] pipeline: Шаг Carmoodo: попытка 1/2.
                          ^^^^^^ код проверки
```

Поиск по коду в `nlc.log` даёт все шаги одной проверки. При непонятном
экране рядом со скриптами сохраняется XML-дамп (`carmoodo_debug_*.xml`,
`heydealer_debug_*.xml`, `adsid_debug_*.xml`), скриншоты PARTSNUMBER — в
`debug_screenshots/`. Дампы старше 14 дней удаляются при старте.

## Устранение неполадок

Порядок всегда один: **`/diag` → посмотреть строки с ❌ → сделать
написанное**.

### ❌ Планшет: ни одного устройства не подключено
Кабель, питание, блокировка экрана. После — `adb devices` должен показать
планшет со статусом `device`.

### ❌ Планшет: состояние «unauthorized»
Планшет виден, но управлять им нельзя. На экране планшета подтвердите
запрос на отладку по USB с галочкой «Всегда разрешать».

### ❌ Appium не отвечает
Обычно окно сервера закрыто. Запустите `appium` в новом окне или
перезапустите `start_all.bat`.

### ❌ ADBKeyBoard не включена
Без неё не вводится корейский текст.

```bat
adb install ADBKeyboard.apk
adb shell ime enable com.android.adbkeyboard/.AdbIME
adb shell ime set com.android.adbkeyboard/.AdbIME
```

### Carmoodo просит войти или зависает на постороннем экране
```bat
adb shell pm clear kr.co.ggkucar.app
```
Затем войдите в приложение вручную и включите **자동로그인** (автовход).

### 🔴 HeyDealer: закончились проверки (10 в сутки)
Лимит привязан к рекламному идентификатору Google устройства. Бот
распознаёт экран «하루 최대 10대까지 조회 가능해요», сам сбрасывает
рекламный ID и повторяет проверку. Вручную — командой `/resetads` или на
планшете: Настройки → Google → Реклама → Сбросить рекламный идентификатор.

Число автоматических сбросов в сутки ограничено `MAX_ADS_RESETS_PER_DAY`.

> **⛔ Никогда не удаляйте аккаунт HeyDealer.** Удалённый аккаунт
> блокируется на 3 месяца («탈퇴하신 계정은 3개월 동안 헤이딜러 앱 이용이
> 불가능합니다»). При лимите правильное действие — только сброс рекламного ID.

### Carmoodo: исчерпан дневной лимит (30 в сутки)
Обнуляется в полночь. Пока лимит исчерпан, бот сразу сообщает причину.
Расход виден в `/status`, предупреждение приходит на 25 из 30.

### Раздел PARTSNUMBER пустой
Каталог доступен только как изображение через VMware Horizon, поэтому это
самый чувствительный шаг; его сбой не мешает остальным разделам отчёта.
Если сбой повторяется на одной марке — поставьте `PARTSNUMBER_DEBUG=1` в
`.env`, повторите проверку и изучите `logs\nlc.log` и `debug_screenshots/`.
При изменении интерфейса каталога координаты перекалибровываются утилитой
`calibrate_partsnumber.py`.

### База проверенных машин
Повторная отправка той же ссылки отвечает из `vehicles.db` мгновенно и не
расходует лимиты. VIN и детали хранятся бессрочно, история ремонта — 30
дней (`REPAIR_HISTORY_TTL_DAYS`).
