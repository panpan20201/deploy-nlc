# Deploy NLC

Telegram-бот: по ссылке Encar / KB Chachacha собирает отчёт о машине —
VIN (Carmoodo), историю ремонта (HeyDealer), детали и дату выпуска
(PARTSNUMBER). Carmoodo и HeyDealer управляются на физическом
Android-планшете через Appium, PARTSNUMBER — через Playwright и
распознавание изображения (VMware Horizon). Python 3.12, Windows.

- Обзор, запуск, неполадки: `README.md`
- Установка на новый компьютер: `docs/INSTALL.md`
- Устройство кода и известные ловушки интерфейсов: `docs/ARCHITECTURE.md`

## Установка системы

Когда просят установить или перенести систему:

1. Иди по `docs/INSTALL.md` по порядку. Автоматическую часть выполняет
   `powershell -ExecutionPolicy Bypass -File tools\setup.ps1`; в конце он
   печатает таблицу OK/WARN/FAIL. Исправляй FAIL и запускай снова.
2. Шаги с пометкой **[вручную]** требуют человека (планшет, аккаунты,
   `.env`, подтверждения Windows). Объясни, что сделать, и дождись
   подтверждения — не пытайся обойти.
3. Эталонные версии — в таблице в начале `docs/INSTALL.md`. Ставь именно
   их (`appium@3.6.0`, `uiautomator2@8.4.0`, `requirements-lock.txt`),
   если человек не просит обновить.
4. `tools\setup.ps1 -ConfigureTablet` меняет настройки планшета — запускай
   с согласия человека.
5. Установка завершена, когда `setup.ps1` проходит без FAIL, ручная
   проверка ссылкой Encar вернула все разделы и `/diag` показывает все ✅.

## Команды

```bat
venv\Scripts\activate
set PYTHONIOENCODING=utf-8
python -m unittest discover -s tests -p "test_*.py"   & rem тесты, без планшета и сети
python bot.py                                          & rem бот (нужен запущенный appium)
start_all.bat                                          & rem вся система
```

Логи: `logs\nlc.log` (DEBUG). У каждой проверки код вида `a3f19c` — он
есть в каждой строке лога этой проверки и в сообщении пользователю.
Дампы непонятных экранов: `*_debug_*.xml` в корне, скриншоты
PARTSNUMBER — `debug_screenshots\`.

## Правила

- **Один экземпляр бота на один `BOT_TOKEN`.** Не запускай `bot.py` с
  рабочим токеном, если бот уже работает (на этом или другом
  компьютере) — экземпляры будут перехватывать сообщения друг у друга.
  Для проверки старта без Telegram есть `tools\setup.ps1`.
- **Никогда не удаляй аккаунт HeyDealer** и не предлагай это: удалённый
  аккаунт блокируется на 3 месяца. Дневной лимит снимается только сбросом
  рекламного ID (`ads_id.py`, команда `/resetads`).
- **Дневные лимиты дорогие:** HeyDealer — 10 проверок в сутки, Carmoodo —
  30. Ручной запуск модулей на планшете (`carmoodo_vin.py`,
  `heydealer_history.py` напрямую) расходует их — спрашивай перед этим.
- **`.env` — секреты.** Не выводи значения в чат и логи, не коммить.
- **`vehicles.db` — главный накопленный актив.** Не удаляй и не
  пересоздавай; перед изменением схемы — копия (`backup.py`).
- **Исправления — только по фактам.** Причину сбоя подтверждай логом,
  дампом экрана или скриншотом, а не гипотезой. Новый случай
  распознавания экрана закрепляй тестом на реальном дампе в
  `tests/fixtures/`.
- **Привязка к интерфейсу:** `resource-id`, а не текст, подсказки или
  координаты. Тексты кнопок — на всех алфавитах (русский, латиница,
  корейский; кириллическое «ОК» ≠ латинское «OK»). Подробности —
  `docs/ARCHITECTURE.md`.
- После любой правки кода прогоняй тесты. Комментарии в коде — на
  русском, объясняют «почему».
